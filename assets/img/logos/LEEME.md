# Logos de las universidades

Guardá acá el logo de cada universidad con estos nombres (SVG, PNG o WebP) y volvé a generar la página. Mientras falte un archivo, la tarjeta muestra la sigla.

| Archivo | Universidad |
|---|---|
| `uba` | Universidad de Buenos Aires |
| `utn` | Universidad Tecnológica Nacional |
| `unlp` | Universidad Nacional de La Plata |
| `untref` | Universidad Nacional de Tres de Febrero |
| `unsam` | Universidad Nacional de San Martín |
| `up` | Universidad de Palermo |
| `kennedy` | Universidad Kennedy |
| `ub` | Universidad de Belgrano |
| `uca` | Pontificia Universidad Católica Argentina |
| `itba` | Instituto Tecnológico de Buenos Aires |
| `uai` | Universidad Abierta Interamericana |

Ejemplo: `assets/img/logos/uba.svg`. Conviene que tengan fondo transparente o blanco: en el sitio se muestran sobre una placa blanca en los dos temas.
